# Product Requirements

## Goal

Create a shopping guide Agent that helps users make ecommerce purchase decisions with trustworthy product knowledge and structured recommendations.

## Users

- Shoppers who need buying advice
- Shoppers comparing similar products
- Shoppers asking about suitability and usage
- Operators who upload product and marketing knowledge

## MVP Features

- Chat-based shopping guide
- Knowledge document ingestion
- RAG answer generation
- Streaming response
- Product card rendering
- Basic feedback collection

## Non-goals for MVP

- Real payment or checkout
- Full order system integration
- Large-scale personalization
- Fine-tuning
