# Evaluation Guide

## Metrics

- Retrieval Recall@K
- Retrieval NDCG@K
- Context Precision
- Context Recall
- Answer Faithfulness
- Answer Relevance
- Product recommendation accuracy
- First token latency
- End-to-end latency

## First Evaluation Dataset

Start with 30 manual cases:

- 10 buying-advice questions
- 5 comparison questions
- 5 suitability questions
- 5 promotion questions
- 5 multi-turn questions

Keep expected products and golden evidence chunks for each case.
